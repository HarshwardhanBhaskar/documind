1 Project Overview

NeuroDocs is a full-stack SaaS (Software as a Service) web application that provides intelligent document processing using Artificial Intelligence. Users can upload PDF and image documents, and the platform automatically performs:

  • OCR (Optical Character Recognition) — extracting text from documents
  • AI Classification — identifying the document type (Invoice, Receipt, Contract, Resume, Certificate, etc.)
  • Smart Field Extraction — pulling out structured data (vendor name, amounts, dates, etc.)
  • Document Summarization — generating concise summaries using AI
  • PDF Utilities — merging, compressing, and converting PDF documents
The application follows a freemium SaaS model with tiered pricing plans that control upload limits and AI processing credits per month.

4.3 AI Processing Pipeline (Powered by Google Gemini)

This is the core feature of NeuroDocs. When a document is processed, it goes through three AI-powered stages:

📄 Upload
→
🔍 OCR
→
🤖 Classify
→
📊 Extract
→
📝 Summarize

Stage 1: OCR (Text Extraction)

  • Digital PDFs → Uses pypdf to extract embedded text (fast, no API call)
  • Scanned/Image files → Falls back to AI-based extraction
  • Stores extracted text in the ocr_text database field

Stage 2: AI Classification (Gemini 2.0 Flash)

  • Fast path: Keyword-based rules check for common patterns first
  • AI path: If keywords aren't confident, sends text to Google Gemini for intelligent classification
  • Classifies into: Invoice, Receipt, Contract, Resume, Certificate, Medical Record, Financial Statement, Legal Filing, Report
  • Returns a confidence score (0.0 to 1.0)

Stage 3: Smart Field Extraction (Gemini 2.0 Flash)

  • Sends document text + detected type to Gemini AI
  • Gemini intelligently extracts all relevant structured fields
  • Falls back to regex-based extraction if API is unavailable
Example output for an Invoice:
{ "vendor": "Acme Corp", "amount": "$24,500.00", "invoice_no": "INV-2024-1192", "date": "March 7, 2026", "due_date": "March 21, 2026" }

Bonus: Document Summarization

Gemini generates a concise 2-4 sentence summary of each document.

7 Security Implementation

JWT AuthenticationEvery API request requires a valid Supabase JWT bearer token
Row Level SecurityPostgreSQL RLS ensures users only access their own documents
Service Role SeparationBackend uses service role key for admin ops; anon key for user auth

File ValidationMIME type and file size validated before upload
